# Member 3 API documentation

All API routes use only `GET`, `POST`, `PUT`, or `DELETE`. Endpoints require a
bearer access token unless stated otherwise.

Use the sole schema source, [DATABASE.sql](../../DATABASE.sql), to create the
database. The application adds no other schema or migration files.
